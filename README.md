## 修改后的必需检查

电脑安装 Node.js 24 后，在仓库目录运行：

```text
node sort-review-check.cjs
```

此命令无需安装第三方依赖。成功时退出码为 0，并显示检查通过；失败时输出完整错误并返回非零退出码。

GitHub 在每次推送、创建或更新拉取请求时自动运行同一检查，也支持在 Actions 页面手动运行。失败会使工作流显示红色失败状态，并出现“任务尚未完成”的错误提示。

执行者的完成门槛见 [AGENTS.md](AGENTS.md)：最后一次修改后的检查必须通过，最终交付须说明检查结果。脚本覆盖排序模式、时间分组、手动顺序、刷新恢复、存储异常以及模拟拖动边界和取消；真实浏览器的画面、动画与指针交互仍按需求文档验收。
